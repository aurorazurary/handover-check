## How to export a Claude Code session

In the Claude desktop app, open the session and use the export option, or run
`/export` in the terminal client. Save the transcript into this folder as
Markdown and add a row to the table above.

Remove nothing from the transcript except API keys. The point of the record is
that it shows what was asked for and what was decided, including the places
where the first answer was wrong.
