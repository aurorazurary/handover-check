That intuition is actually spot on — you've got the whole concept already, including the 5-vs-500 example, which is exactly the right way to think about it.

Here's the framing to pin it down: **micro average pools all the examples together and divides once** — a bucket with ten thousand examples moves the number far more than one with fifty. **Macro average works out the accuracy inside each bucket first, then averages those** — so every bucket carries the same weight however small it is. Think of it like a year group of students: **micro is the average mark across every student regardless of class; macro is the average of each class's average, so a class of five counts as much as a class of fifty.**

```python
def cached_predict(model, batch):
    key = sha1(''.join(batch.texts).encode()).hexdigest()
    path = Path('.cache') / f'{key}.pt'
    if path.exists():
        return torch.load(path)          # note: key does not include the model checkpoint
    out = model(batch)
    torch.save(out, path)
    return out
```

What it does: it memoises model outputs on disk in `.cache/`, keyed by a hash of the input text. Re-run the eval on the same data and, instead of doing a forward pass, it loads the saved tensor straight off disk — much faster, especially for a large eval set.
